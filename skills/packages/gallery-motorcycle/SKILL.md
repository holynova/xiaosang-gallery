# 导演与机车

## 准备

先确认主体、视角和配色。查看下面的参考图，提取构图、光色和材质特征。将用户提供的事实、题材照片或原文作为内容依据，单独标明用途。

- [张艺谋 / Zhang Yimou](assets/motorcycle-7197533f8cf2b.webp)
- [王家卫 / Wong Kar-wai](assets/motorcycle-d25758e060cfd.webp)

## 模板

用【主体】做一张机车主题电影剧照。采用【视角与场景】安排景别、道路和人物，使用【配色与材质】确定色温、阴影、颗粒和反光。镜头线索从画面出发，形成独立场景。

## 填写示例

用张艺谋 / Zhang Yimou做一张机车主题电影剧照。采用华语导演安排景别、道路和人物，使用电影感摄影确定色温、阴影、颗粒和反光。镜头线索从画面出发，形成独立场景。

## 输出

仅要求提示词时返回填好的文本。要求成图时，使用可用的图像生成工具，记录实际输入的提示词。检查主体辨识度、构图和材质，针对实际偏差修改。涉及文物、建筑和知识内容时，校对可验证的事实以及示意或推断标记。
