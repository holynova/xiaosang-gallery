# 游戏画风转译

先确认主体、视角和配色。查看下面的参考图，提取构图、光色和材质特征。将用户提供的事实、题材照片或原文作为内容依据，单独标明用途。

- [Animal Crossing: New Horizons](assets/gamestyle-ac.webp)
- [Cyberpunk 2077](assets/gamestyle-cyber.webp)

## 模板

把【主体】转译为一幅游戏实机风格的场景。遵循【视角与场景】中的机位和地标体量，按【配色与材质】重构颜色分级、材质、天气与光。把画风参考和原景结构分开校准。

## 填写示例

把Animal Crossing: New Horizons转译为一幅游戏实机风格的场景。遵循静安寺中的机位和地标体量，按场景转译重构颜色分级、材质、天气与光。把画风参考和原景结构分开校准。

## 输出

仅要求提示词时返回填好的文本。要求成图时，使用可用的图像生成工具，记录实际输入的提示词。检查主体辨识度、构图和材质，针对实际偏差修改。涉及文物、建筑和知识内容时，校对可验证的事实以及示意或推断标记。
